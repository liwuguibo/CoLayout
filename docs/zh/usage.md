# 软件使用说明

**简体中文** | [English](../en/usage.md) · [项目首页](../../README.md) · [文档目录](index.md)

## 工作区

APP 只维护一份权威本地文档。人和 API 客户端共享对象、操作区、UID 和撤销语义。本地操作区是组织工作的方法，不会在 Virtuoso 中创建新的子 cell。

工艺审核后，从“文件”菜单显式导入目标 Layout 及其对应的原理图参考。真实物理目标来自 Layout 的 PIN／网络；原理图辅助理解电路、匹配与设计意图。它不替代实际几何连接。

框出需要工作的器件建立操作区，检查接口，把操作区 ID 交给版图 Agent。暂时没有实体接入的接口可以作为待补义务保留，后续保护环或连线仍必须真正接通；虚拟 PIN 标记不会凭空产生金属。

## 一个基本协作流程

1. 人选择源版图并划分本地操作区。CoLayout 会自动把不可制造的操作区警示框（`[CoLayout AI Region: ...] DO NOT EDIT INSIDE`）同步绘制到 Virtuoso 中，提示区外人类避让。
2. 每个版图 Agent 接入用户分配的区域。兄弟区可并行；父区只管理直接子区外框和接口。同时，人类仍可直接在 Virtuoso GUI 中编辑所有操作区之外的版图。
3. 按需要先用方位 PIN 模式完成内部主体，补齐器件接入、布线和已配置的保护环。
4. 使用属性面板／API 收紧操作区，切换固定 PIN，完成到边缘接口的真实引出。
5. 高频运行本地检查并查看提醒，在合适阶段运行服务器 DRC；当前全区两项证据均通过后才能完成验收。
6. 人（或已验收区域通过 API `release_region(sync_to_virtuoso=True)` / `workspace sync`）显式将核对后的工作区改动协同写入 Virtuoso，无需等待其他仍在工作中的操作区全部结束；最终由人完成全芯片检查、LVS 和签核。

Agent 占用时，CoLayout 内该操作层的人类物理编辑会锁定，查看和导航仍可用；定位框是有限的实时指导例外。不要通过结束其他客户端会话来绕过锁定。在 Virtuoso 端编辑时，请仅在所有操作区警示框之外修改并在需要合并前按 `F2` 保存。

## Virtuoso 与 CoLayout 解耦协同编辑

CoLayout 将人类在 Virtuoso GUI 中的全局/区外设计与 AI 在本地操作区（`OperationRegion`）内的编辑解耦，只要两者编辑的物理区域完全错开，任一方完成后都可随时合并推送，互不影响：

- **Virtuoso 操作区警示边界自动同步**：在 CoLayout UI 或通过 Agent API（`workspace create_region` / `dissolve_region`、调整边框或收紧区域）更新操作区后，系统会自动在 Virtuoso 对应窗口通过瞬态高亮集（`geCreateHilightSet`）刷新不可制造警示边界（`marker/warning` 与 `y0/drawing` 边框及 ASCII 标签 `[CoLayout AI Region: <名称/ID>] DO NOT EDIT INSIDE`）。警示仅作视图提醒，不会改动 OA 数据库、不会污染 Layout XL 提取状态或使窗口变为未保存，也不会进入本地工作区快照与 Calibre 检查副本。必要时也可通过 `workspace sync_regions` 手动重绘。
- **随时读取 Virtuoso 区外改动（`读取` / `workspace pull`）**：当人类在 Virtuoso 中修改操作区以外的版图并保存（`F2`）后，点击工具栏 **“读取”**（`文件 → 读取服务器`）或调用 Agent `workspace(action="pull")` 即可立即将区外改动合入工作区基线。与整工作区重导不同，协同 `pull` **不会清空本地未提交草稿（`operations`），也不会中止未受影响的活跃 Agent 操作区租约**。（若需彻底丢弃本地工作区并用服务器版图替换，请使用 `文件 → 从 Virtuoso 重新导入…`，该操作仍要求所有会话空闲。）
- **随时推送已完成区域回 Virtuoso（`写入` / `workspace sync` / `release_region`）**：当部分操作区已完成验收（退出 Agent 占用），即使另有兄弟操作区仍由其他 Agent 占用编辑，点击 **“写入”**（`文件 → 写入 Virtuoso`）、调用 `workspace(action="sync")`（可指定单个已完成 `region_id`），或在 `release_region(outcome="done", sync_to_virtuoso=True)` 时，CoLayout 会自动先合入 Virtuoso 最新区外改动，再**按该操作区最终审查快照与 `colayoutObjectId` 无历史覆盖写入**（不依赖中间编辑历史：区内未改动走线/`oaRoute` 原地保留、器件 `inst` 原地更新位姿以保留 Layout XL 原理图绑定、已删除/修改/新增的可写导线/标准过孔/保护环直接覆盖写入）并保存重绘，同时在本地完整保留仍在运行中的兄弟操作区草稿与租约。
- **越界与未保存保护（安全拦截）**：
  - `VIRTUOSO_UNSAVED_CHANGES`：检测到 Virtuoso 当前 cellview 仍有未按 `F2` 保存的编辑（`modifiedButNotSaved=t`）时拒绝同步。请先在 Virtuoso 保存或还原后再重试。
  - `VIRTUOSO_EDIT_IN_REGION`：无论“读取”还是“写入”，一旦检测到 Virtuoso 中存在**落入或跨入任何操作区**的新增、移动/修改或删除操作，CoLayout 会立即中止协同合并，完整保留双方原有工作，并在报错信息中明确列出越界元素的名称、类型、图层、微米坐标范围及被侵入的操作区名称。请在 Virtuoso 中删除或移出越界元素并保存（`F2`）后重新点击“读取”或“写入”。

## 铺铜

顶部“矩形”按钮的二级菜单中，“矩形”和“铺铜”并列。铺铜支持在拖出的矩形内生成指定金属层和网络的铜皮，图层下拉与矩形创建共用同一套 LPP 选择行为，但只列出可写金属 drawing 层。可先选择要连接的本层普通图形/过孔，再打开面板；间距默认值取该层已配置的最大本地 spacing，未配置时为 0.2 µm，可按工艺要求调整。面板中的 45° 拐弯复选框默认关闭。未选连接目标时保留所有独立铜岛；选定目标后删除未连接铜岛。已有不同网络标记的目标、越界范围或不完整几何会整次拒绝。

铺铜避让所有未明确指定的同层金属，并遵守禁布区和黑盒策略。默认模式下，斜线障碍使用保守轴对齐包围，结果为仅含水平/垂直边的普通可编辑多边形，支持 L 形、U 形等凹角；带孔区域经过正交切片并重新合并为无孔简单多边形。勾选 45° 拐弯后允许 45°/90° 边，支持的 45° 斜障碍按实际 45° 轮廓避让，非支持角度仍使用保守轴对齐包围；输出切片同样合并为无孔简单多边形。单次最多 512 个多边形，一次 Ctrl+Z 撤销整批。网格取整会额外留出少量间距。该功能只保证显式障碍间距，不替代最小宽度、密度、天线、电热或完整 DRC/LVS 检查，生成后仍应运行本地与服务器验证。

## 按需本地 RC 寄生影响评估

顶部“画线”按钮打开就近参数弹层，点击开始画线后弹层自动收起以留出完整画布视野。“画线”支持未确认的正交折线（L 形）草稿：单击加点、移动实时预览 L 形双段或单段正交延伸、按 `Space` 在“先横后竖 / 先竖后横 / 单段正交”间翻转折弯方向、右键撤销上一步加点；按 `[` / `]`（或 `PageDown` / `PageUp`）在金属栈间上下换层并自动带出该层默认线宽与对应标准过孔，转折锚点实时显示过孔包封框与切孔阵列预览。Enter／双击通过现有 Editor 事务一次性提交，Esc 放弃草稿。不会为了提交而新增全区连通或 DRC 全通过门槛，原有权限、版本和几何约束仍然有效，允许分步布线。

**无持续后台自动计算**：交互式画线（`WireCapture` / `WirePanel`）、鼠标拖拽（`MouseEdit`）、自动布线浏览及提交动作均**不进行任何连续或无触发的后台 RC 估算**，避免日常版图编辑期间产生多余的本地 CPU 负载。

在工艺库中审核 RC 模型后（可使用解析系数，或通过 `surrogate` 配置本地纯 NumPy Geo-Graph 神经网络权重与层叠堆栈），用户与 Agent 均可**按需选择性评估 RC 寄生影响**：
- **画线后即时查看**：在 `WirePanel` 提交走线后，可直接点击 **“查看本次走线 RC”** 按钮打开 **“RC 寄生影响”** 工具页，对刚布好的几何进行针对性评估（对比修改前的基线获得 `ΔR / ΔCg / ΔCc`）。
- **面板按需计算与清除**：在 **RC 寄生影响** 面板（`视图 → RC 寄生影响`）中，用户可选中对象、追踪网络、预览自动布线候选，按需调整 **近邻范围**（`µm`），然后点击 **“计算当前 RC”** 执行按需计算，或点击 **“清除”** 清除结果与画布高亮。后续任何版图编辑操作会标记已有结果为过期状态（显示 `版图已更新（未自动重算）· 点击“计算当前 RC”更新`），绝不自动持续重新计算。

`Ca/Cp` 不包含已显式枚举的邻域效应；同一物理分量内部不计算耦合，每个耦合对只计一次，未知网络不会默认为异网。开启过孔感知神经网络代理时，先画上下金属再单独落孔会自动合并连通网络并抵消原先层间耦合，结合 3D 节点电导求解给出等效电阻；未启用或任意多边形／拓扑不明时不报告端口等效电阻，也不计算 RC 延迟。所有交互评估均基于本机冻结几何与审核系数，不调用 SSH、Virtuoso、Calibre 或网络。黑盒只提供筛选后的公开 PIN，不展开内部。超出模型范围、缺少系数或几何过复杂会明确显示，不阻止正常编辑。

**共享人机 RC 评估 API**：人端 UI 与 Agent API 调用完全相同的底层领域服务（`evaluate_parasitics_outcome` / `evaluate_parasitics`），Agent 可通过 `inspect_region(kind="parasitics")` 或 CLI（`api.py inspect parasitics`）按需查询。此面板与接口仅提供早期设计阶段的趋势参考（`signoff: false`），不能替代 DRC、LVS 或 Calibre 正式签核。

## 图层调色板、标尺与协作辅助

- **图层调色板（LSW）**：点击顶栏“图层”可在左侧分栏查看当前工艺金属层、切孔层与器件层色标。勾选可按层显隐；单击可写层自动联动“画线 / 矩形 / 铺铜”的目标层；**双击任意图层进入“独显（Solo）”模式**（金属层独显时保留相邻连接过孔切孔层），再次双击或点“退出独显”恢复原显隐状态。图层显隐纯属人端视图过滤：被隐藏图层不会拦截点选或框选，也不影响本地/服务器 DRC、同步或 Agent 截图。
- **交互标尺（Ruler）**：点击顶栏“标尺”或按 `K` 进入测距，自动吸附制造网格与附近可见图形边缘/角点（按住 `Shift` 仅按网格吸附），`Space` 切换正交与斜向分量显示，单击起点与终点放置标尺，`Shift+K` 清除当前层全部标尺。标尺仅保存在当前会话视图中，不写入工作区历史。
- **底栏实时读数与锁线切换**：底栏右侧常驻显示网格吸附后的光标微米坐标，并在画线、标尺、拖框、移动对象期间实时显示相对位移 `Δ(ΔX, ΔY)` 与长度/尺寸；底栏“锁线 / 移线”胶囊按钮可直接切换“点击查网（防误触锁定）”与“允许拖动金属线和过孔”。
- **复制任务上下文**：在“编辑 → 复制任务上下文”或操作区右键菜单中，可一键复制当前操作区名称、ID、范围、接口 PIN 与定位框/禁布区摘要，便于直接粘贴给版图 Agent 对话。

## 层次与局部布线豁免

普通叶 PCell 参与本地／服务器检查，真正的原生层次对象保持黑盒。如果公开 PIN 位于黑盒内部，可以为该对象的指定金属层设置局部布线通道。它不开放内部编辑，也不豁免其他对象或独立禁布区。

APP 子操作区与原生层次是两套结构。子区内部由其自身 Agent 负责；父层移动子区外框时，内容整体变换，并按依赖关系使相应旧结果失效。

## 检查结果分别代表什么

工艺库的“绘图与图层”页可勾选“允许 Agent 使用算法自动布线”，默认关闭（含旧配置）。只有人保存/审核后才向 Agent 开放 route_region；人类 UI 自动布线不受影响，排列、对齐、自动过孔等其他 Agent 工具也不受影响。

“收紧操作区”按内容及直接子区 PIN 外形保留适量通道：各方向取最大 PIN 尺寸的一半，再加约 10%（至少一个制造网格）。UI 与 API 一致，保留 PIN 模式和原生几何，只在原框内收紧；原框过紧时不额外提示。

- 本地连通检查针对公开目标和已支持材质，不抽取完整器件内部电路。
- 本地 DRC 包含已配置的简单几何规则、设计提醒、跨器件 Poly 冲突、已配置 MIM 区域过孔防护和内部金属误接提醒。不支持的宽度几何直接跳过。
- 内部金属接触是非阻断 warning；真实物理错误，以及不完整、过期、截断的检查仍阻断完成。
- 服务器 DRC 使用包含当前本地修改的原生私有副本，按人批准的工艺报告策略审阅，同时保留原始结果。
- 两项区域检查通过，不等于全芯片 DRC 或 LVS 签核。

不要为了消除结果而改器件参数或自行增加豁免。若协同读取或写入因 `VIRTUOSO_EDIT_IN_REGION` 中止，应先在 Virtuoso 中清理或移出落入操作区的元素并保存；若遇到依赖变化或事务对账基线不符，先核对服务器源或持久日志中的实际变化，再执行恢复／同步。

审核本地规则时，source/note 只是依据和说明，不会自动实现区域例外或电气条件。有用的简化检查通常应保持启用，允许因遗漏条件造成有限误报，并审核备注中的简化范围及可能漏检。只有依据不足、算法无法执行，或频繁误报合法基础结构以至于影响使用时，才禁用。备注不代表遗漏条件已经实现，完整服务器 DRC 仍然需要执行。

本地 `spacing` 不区分同网/异网，也不比较网络名称；规则 ID 不会选择原始 deck 的条件。同层启用多条间距规则时全部执行，检查覆盖范围内须满足最大启用阈值，并非按条件选择阈值。配置者须根据当前 PDK 选择有依据的简化检查，明确实际行为、原始依据及未覆盖项；配置检查通过不代表已实现原始条件。版图 Agent 不能根据规则名称或备注推断额外能力，也不能自行修改工艺配置绕过检查。

## 保存、加载和恢复

APP 自动维护内部工作副本和恢复记录；“保存／另存为”才更新用户指定的便携 JSON 存档。之后继续编辑不会不断改写该存档。

Agent 的 workspace save 生成独立快照；load 与人端打开存档的语义一致，先备份，再替换整个当前工作区。它要求会话和任务空闲、没有未决原生事务，也不会自动同步 Virtuoso。

请求超时不代表未执行。保留原 request_id、body 和 pending，查询或重试同一个请求；不要换 ID 再创建一次。原生写入不确定时保留回执，走核对恢复流程，不清记录绕过失败。

## 常用默认快捷键

| 按键 | 功能 |
|---|---|
| F | 适合窗口 |
| K / Shift+K | 启动标尺测距 / 清除当前视图标尺 |
| Space（画线或标尺中） | 翻转画线 L 形折弯姿态 / 切换标尺正交与斜向 |
| [ / ]（画线中） | 切换下一段下层 / 上层金属并自动匹配过孔 |
| Ctrl+E | 返回上层 |
| Ctrl+R | 旋转所选支持对象 90° |
| Ctrl+Z 或 U | 撤销 |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做 |
| Ctrl＋滚轮 | 切换层次透视程度 |
| Esc | 取消当前交互 |

快捷键可在人端设置，输入框内仍保留文字编辑行为。面板按钮用于开关对应面板；自动布线与 RC 寄生影响入口位于“视图”菜单。
